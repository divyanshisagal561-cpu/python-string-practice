# 🐍 Python String Practice & Validation

A beginner-friendly Python project designed to practice and strengthen **String Manipulation, Indexing, Slicing, String Methods, Loops, Conditional Statements, Dictionaries, and Input Validation**.

This project contains a collection of practical string exercises followed by a **Username & Password Validator** mini-project.

---

## 📌 Project Overview

Strings are one of the most commonly used data types in Python. This project provides hands-on practice with different string operations and demonstrates how they can be combined to solve practical programming problems.

### 🎯 Objectives

* Understand Python strings and indexing
* Practice string slicing
* Work with built-in string methods
* Perform string searching and replacement
* Split and join strings
* Validate string content
* Count vowels, consonants, digits, and spaces
* Reverse and check palindrome strings
* Count character frequency using dictionaries
* Build a basic credential validation system

## 🧩 Exercises Included

### 1. Create and Access a String

Demonstrates how to:

* Create a string
* Access the complete string
* Find the first and last character
* Extract the first and last five characters

### 2. String Length

Calculates string length using:

* Python's `len()` function
* A `for` loop as an alternative approach

### 3. String Indexing

Practices accessing characters using:

* Positive indexes
* Negative indexes

### 4. String Slicing

Demonstrates:

* Extracting `"Python"`
* Extracting `"Programming"`
* Reversing a string
* Extracting every second character
* Extracting every third character

### 5. Case Conversion

Practices:

```python
upper()
lower()
title()
capitalize()
swapcase()
```

### 6. Removing Extra Spaces

Demonstrates the difference between:

```python
strip()
lstrip()
rstrip()
```

### 7. Searching Inside Strings

Uses:

```python
find()
count()
```

to locate and count specific words.

### 8. Replacing Characters or Words

Uses `replace()` to substitute occurrences of one word with another.

### 9. Split and Join

Practices converting strings into lists and joining them using different separators.

### 10. Checking String Content

Uses Python's `is...()` methods to determine whether a string contains:

* Alphabets
* Digits
* Alphanumeric characters
* Spaces
* Uppercase characters
* Lowercase characters

### 11. Counting Vowels and Consonants

Analyzes user input and counts:

* Vowels
* Consonants
* Digits
* Spaces

Special characters are ignored.

### 12. Reverse a String

Uses string slicing to reverse user input.

Example:

```text
Input:  Python
Output: nohtyP
```

### 13. Palindrome Checker

Checks whether a string reads the same forwards and backwards.

Example:

```text
Input:  madam
Output: Palindrome
```

### 14. Character Frequency

Uses a dictionary to count how many times each character appears in a string.

Example:

```text
p : 1
r : 2
o : 1
g : 2
a : 1
m : 2
i : 1
n : 1
```

# ⭐ Mini Project: Username & Password Validator

The project concludes with a simple **Username & Password Validator**.

The program accepts a username and password from the user and checks whether they satisfy the required conditions.

### Username Requirements

* Contains only letters and numbers
* Contains at least 5 characters

### Password Requirements

* Contains at least 8 characters
* Contains at least one uppercase letter
* Contains at least one lowercase letter
* Contains at least one digit

If all conditions are satisfied:

```text
Valid credentials
```

Otherwise, the program displays the relevant validation message.
